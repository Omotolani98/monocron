# Monocrond

The monocron daemon that handles all unix sockets calls received from monocronctl to start and execute cron jobs on the machine level.

## Usage

Start Daemon

```bash
monocrond start &
```
Ampersand is to run program as a background task, This will be fixed in future updates

Stop Daemon

```bash
monocrond stop
```
Gracefully shuts down the daemon
